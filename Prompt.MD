Initial Project Prompt

Build a Netflix-inspired movie discovery web application using React and Vite.

The application should allow users to:

- Browse popular, top-rated, and upcoming movies
- Search movies using TMDB API
- View detailed movie information on a separate page
- Save favorite movies using localStorage
- Support responsive design for mobile and desktop devices
- Implement infinite scrolling for movie lists
- Include a simple login system with protected routes
- Use React Router for navigation
- Organize code into reusable components and custom hooks

AI Mood Matcher Feature

Create a feature called "Mood Matcher" where users can describe their mood in natural language.

Examples:

- "I want something exciting"
- "Recommend a dark thriller"
- "I want a feel-good movie"

Use Claude AI to understand the user's mood and recommend a suitable movie. After receiving the recommendation, fetch movie details from TMDB and display them in the application.

Technical Requirements

- React 18
- Vite
- Tailwind CSS
- React Router v6
- TMDB API
- Claude API
- Context API for authentication
- localStorage for persistence

Additional Requirements

- Debounced search input
- Lazy loading images
- Infinite scrolling
- Responsive UI
- Clean folder structure
- Reusable components
- Good user experience and performance

Goal

The goal is to build a real-world React single-page application that combines movie discovery, AI-powered recommendations, authentication flow, and state management while following clean development practices.
